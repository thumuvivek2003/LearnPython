## 📘 Python for Absolute Beginners
| S.No   | Topic Name                  | Description                                                                                  | Learning Outcomes                                          |
| ------ | --------------------------- | -------------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| **1**  | Introduction to Python      | What is Python? Why Python is popular? Installing Python & writing your first code (`print`) | Understand Python basics & run your first script           |
| **2**  | Variables & Data Types      | Storing information in variables, understanding `int`, `float`, `str`, `bool`                | Store different types of data and use them properly        |
| **3**  | Input & Output              | Using `input()` & formatting text with `print()`                                             | Take user input and display meaningful output              |
| **4**  | Operators & Expressions     | Arithmetic, comparison, logical, assignment operators                                        | Perform calculations and decision comparisons              |
| **5**  | Conditional Statements      | `if`, `elif`, `else` — Making decisions in code                                              | Build programs that react to conditions                    |
| **6**  | Loops                       | `for` and `while` loops — Repeat actions efficiently                                         | Solve repetitive tasks without copying code                |
| **7**  | Strings                     | String basics, slicing, built-in functions                                                   | Manipulate and format text effectively                     |
| **8**  | Lists                       | Ordered collections, indexing, list methods                                                  | Store & manage multiple data items easily                  |
| **9**  | Tuples & Sets               | Immutable data (tuples), unique data (sets)                                                  | Choose right data structures confidently                   |
| **10** | Dictionaries                | Key-value pairs, CRUD operations                                                             | Store and access real-world mapped data                    |
| **11** | Functions                   | Modular programming using `def`, parameters, return values                                   | Write reusable, clean, and organized code                  |
| **12** | Error Handling              | Exceptions, `try-except` blocks                                                              | Prevent program crashes & handle errors smartly            |
| **13** | File Handling               | Read/write text files                                                                        | Store data permanently in files                            |
| **14** | Modules & Libraries         | Importing Python built-ins and external libraries                                            | Use powerful tools without writing everything from scratch |
| **15** | Introduction to OOP         | Classes, objects, attributes, methods                                                        | Understand basics of object-oriented programming           |
| **16** | Working with Packages (pip) | Installing and using packages                                                                | Expand Python with thousands of ready-made tools           |
| **17** | Basic Projects              | Simple games & utility apps to reinforce all topics                                          | Combine all skills to build real mini-projects             |
