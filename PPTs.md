# ⭐ Lesson 9 — **Tuples & Sets**

## 🔶 Slide 1 — What Are Tuples & Sets?

Both store multiple values like lists, but:

| Feature             | Tuple | Set   |
| ------------------- | ----- | ----- |

| Order kept?         | ✔ Yes | ❌ No  |

* **Immutable** → cannot change
* Uses **( )**
* Keeps order

```python
student = ("Vivek", 21, "India")
```

* Data should **not** change
  Example: Coordinates, Dates, Settings

* Safer + Faster than lists ✔
